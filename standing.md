# Game Standing

Scope: active top-level game projects only. Archived projects under `archive/`, shared tooling such as `macroquad-toolkit`, and starter templates are excluded.

Last updated: 2026-08-12

Criteria: ranked by MVP scale and apparent implementation complexity, mainly Rust code size, system count, data/assets, and how much game state the project appears to manage. This is not a fun/polish ranking. LOC/file counts are a fresh recount of `*.rs` beneath every `src/` in each repository, including sibling crates; tests are counted across repository Rust sources. Generated build output is excluded. The shared source gate now permits 800 non-test lines per file, so extracted `tests.rs` modules have increased file counts in several projects without equivalent feature growth.

**Movement this pass is broad again.** Three new active games enter the list: `mirexis` (~24.0k LOC, a complete identity-branched tactical campaign built in four days), `planetfall_engineer` (~8.2k LOC, a deterministic 3D fluid-engineering vertical slice), and the previously omitted `hatchspire` (~10.6k LOC, now carrying a large generated-art integration pass). The absent `monstron` repository drops out; `hatchspire` explicitly treats that old Unity prototype as inspiration rather than a port. The largest existing movers are `monsterhall` (+8.7k LOC), `apartment` (+6.5k), `dungeon_core` (+5.5k), `toybox` (+8.3k), and `alchemy_tower` (+9.2k). `stellar_legacy` added inherited-obligation and institutional-continuity releases; `nightmare_shift` completed seeded/daily runs, its true ending, audio/accessibility, and a planned-art pass. A three-commit documentation/standards sweep touched almost every otherwise-quiet repository and is not treated as feature movement.

**Finish estimates:** each game carries a rough estimate of how long a full-time team of 4 (mixed engineering / art / design-audio, or generalists managing outsourced assets) would need to take the current codebase to a finished, shippable 1.0: content-complete, balanced, QA'd, with placeholder/procedural artwork replaced where that is not the intended visual direction, plus a full sound/music pass. Estimates are calendar months and are order-of-magnitude planning numbers, not commitments.
