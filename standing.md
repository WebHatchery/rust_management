# Game Standing — itch.io HTML5 Readiness

Scope: 37 active top-level game repositories. Archived projects, `macroquad-toolkit`, `rust_management`, templates, build outputs, and other shared tooling are excluded.

Last updated: 2026-09-02

Method: ranked by the shortest honest path from the repository as it exists today to a public, self-contained, playable HTML5 release on itch.io. The review follows the player journey rather than implementation size: first launch and onboarding, a satisfying repeatable or finite loop, touch-visible browser controls, failure and recovery, save continuity, content and ending coverage, presentation, current verification evidence, and an actual itch packaging path. Rust line counts are deliberately not used.

Scoring: 90–100 is live or release-candidate work; 80–89 is a complete game needing one concentrated acceptance or polish gate; 70–79 is a playable alpha with a material onboarding, input, ending, or browser gap; 60–69 is a credible vertical slice that still needs a bounded release arc; 40–59 is dependency-bound or missing a release-defining player journey; below 40 is foundational work rather than an itch candidate. Scores are prioritisation aids, not completion percentages.

Ship windows: estimates assume one focused developer, prompt access to testers, reuse of the current assets and tooling, and a deliberately scoped public-playable release rather than a fully polished 1.0. The window covers the named blocker and routine packaging, not marketing, external store review, or waiting for owner decisions. A missing `itch.json` is treated as a small packaging task unless it is the only gate left or reflects an unresolved deployment decision.

Evidence pass: every repository's current README, design/TODO/release documents, recent history, player-facing metadata, source flow, content, verification captures, WebGL output, and itch configuration were inspected. Fresh local test runs also passed for `planetfall_engineer`, `realmseed`, `scrapyard`, `sentience`, `stellar_legacy`, `tarrowyn`, `tb_realms`, `the_enchanters_ledger`, `toybox`, and `world_machine`; other test and publish results below are explicitly repository-recorded evidence rather than reruns in this pass.

Portfolio read: 10 games are on a credible immediate release path, another 8 have complete playable loops but still need a concentrated acceptance pass, and the remaining 19 need a more material release arc, input overhaul, or online dependency. Every game has the shared itch wrapper, but only `idle_hands`, `apartment`, and `world_machine` currently name usable itch destinations; `planet_trader` still carries a placeholder target. Packaging is therefore widespread unfinished work, but it is not allowed to hide a more important gameplay blocker.
