# Game Standing

Scope: active top-level game projects only. Archived projects under `archive/`, shared tooling such as `macroquad-toolkit`, starter templates, and nested management projects are excluded.

Last updated: 2026-08-19

Criteria: ranked by MVP scale and apparent implementation complexity, mainly Rust code size, system count, data/assets, and how much game state the project appears to manage. This is not a fun/polish ranking. LOC/file counts are a fresh recount of tracked `*.rs` beneath every `src/` in each repository, including sibling crates; tests are counted across repository Rust sources. Generated build output is excluded. The shared source gate now permits 800 non-test lines per file, so extracted `tests.rs` modules can increase file counts without equivalent feature growth.

**Movement this pass is the broadest yet.** Three active top-level games enter: `idle_hands` (~43.8k LOC, a playable 47-game touch-first cabinet), `tarrowyn` (~15.9k LOC, a Phase 6 authoritative client/server realm), and `last_assembly` (~12.5k LOC, a tower-defense/factory survival game). `nanite_swarm` closed its implementation TODO across logistics, win condition, simulation, save recovery, UX, audio, and release validation; `carriage_run` closed its release backlog; `frontier` completed its shell/combat/evaluator/verification pass; and `dungeon_core` closed its readiness, VFX, and soak gates. `auction_game`, `realmseed`, `monsterhall`, `master_thief`, `alchemy_tower`, `biofoundry`, and `hatchspire` also received substantial feature, art, or presentation passes. The 8/13 asset-registry migration and 8/19 metadata/itch sync commits are housekeeping and are not treated as feature movement.

**Finish estimates:** each game carries a rough estimate of how long a full-time team of 4 (mixed engineering / art / design-audio, or generalists managing outsourced assets) would need to take the current codebase to a finished, shippable 1.0: content-complete, balanced, QA'd, with placeholder/procedural artwork replaced where that is not the intended visual direction, plus a full sound/music pass. Estimates are calendar months and are order-of-magnitude planning numbers, not commitments.
