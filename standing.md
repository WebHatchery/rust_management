# Game Standing

Scope: active top-level game projects only. Archived projects under `archive/`, shared tooling such as `macroquad-toolkit`, and starter templates are excluded.

Last updated: 2026-07-18

Criteria: ranked by MVP scale and apparent implementation complexity, mainly Rust code size, system count, data/assets, and how much game state the project appears to manage. This is not a fun/polish ranking. LOC/file counts below are a straight recount (`*.rs` under each project's `src/`) taken fresh this pass, so figures may differ slightly from earlier snapshots even where nothing changed — treat drift within a few percent as noise, not movement.

**Finish estimates:** each game now carries a rough estimate of how long a full-time team of 4 (mixed engineering / art / design-audio, or generalists managing outsourced assets) would need to take the current codebase to a finished, shippable 1.0 — content-complete, balanced, QA'd, with **all placeholder/procedural artwork replaced by commissioned art and a full sound/music pass**. Estimates are calendar months, dominated as much by asset volume (creature rosters, card illustrations, animation sets) as by remaining code. Treat them as order-of-magnitude planning numbers, not commitments.
